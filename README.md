# keyboard

This is a 64 key custom keyboard, slightly wider than a typical 60% keyboard. It uses an 8x8 key matrix, hence the 3 extra keys not typically included in a 60% keyboard. Those keys will be mapped to media controls in firmware. Firmware and 3D models of the case will be added shortly, along with the full bill of materials and CAD files of the full project. The project uses the Raspberry Pi Pico 2 microcontroller.

For assembly, snap the switches into the holes and place the diodes, paying close attention to orientation. Also, solder pin headers to the Raspberry Pi Pico 2 and solder those in the PCB. Snap in the stabilizers and add the keycaps. Then, put the microcontroller in boot mode with circuitpython and add the firmware. I will add CAD files for an enclosure shortly, along with photos of the finished product.
